# Black Russia — Мурманск AdminTools

Публичный frontend-репозиторий оболочки панели администрации.

## Возможности интерфейса

- обычный администратор и руководство;
- главная страница и профиль;
- уведомления;
- нормативы;
- обращения;
- состав администрации;
- журнал действий;
- управление доступом;
- регламент;
- водяной знак с никнеймом;
- таймер сессии;
- сохранение входа через cookies по выбору «Запомнить меня»;
- подготовленный блок статистики сервера (название, онлайн, состояние и цвет статуса);
- адаптация для телефона и ПК.

## Архитектура

Репозиторий содержит только публичную оболочку.

Frontend отправляет авторизационные запросы в закрытую Supabase Edge Function `veb-tools`. Серверный код и секреты не хранятся в публичном репозитории.

## Структура

- `index.html` — точка входа;
- `css/app-v11.css` — стили интерфейса;
- `js/app-v11.js` — интерфейс, навигация и представления;
- `js/api.js` — frontend-коннектор к Edge Function;
- `js/diagnostics.js` — диагностика frontend.

## Примечание

Публичный репозиторий содержит только frontend. Серверная логика остаётся в Supabase Edge Function и не публикуется в GitHub.
