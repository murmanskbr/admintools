# AdminTools

Веб-панель для администраторов сервера **Black Russia — Мурманск**.

Сайт предназначен для повседневной работы администрации в одном месте: здесь можно смотреть и отправлять нормативы, работать с обращениями, отслеживать связанную активность, получать уведомления и управлять доступом администраторов.

## Что сейчас есть

- Работа с аккаунтом администратора и защищённым доступом к панели.
- Работа с нормативами и их историей.
- Обращения и связанные административные действия.
- Уведомления внутри панели.
- Уведомления **Push** прямо на устройство.
- Поддержка Push на **Android** и **Windows/ПК**.
- В настройках можно включить или отключить Push на конкретном устройстве.
- Руководство может видеть, у каких администраторов включены Push-уведомления и на каких устройствах.
- Новые уведомления из панели могут дополнительно приходить как системные Push-уведомления.
- При полном удалении администратора удаляются его аккаунт и связанные с ним рабочие данные и история, чтобы не хранить ненужную информацию.

## Последнее обновление — 7 октября 2026

В панель добавлена полноценная система **Push-уведомлений**.

Теперь администратор может включить Push в настройках сайта и получать важные уведомления даже тогда, когда сама страница панели не открыта. Для руководства добавлен просмотр состояния Push у администраторов.

Также обновлена логика удаления администратора: при полном удалении больше не остаётся ненужная история, связанная с его работой в панели.

## Назначение проекта

AdminTools создаётся как единая рабочая панель администрации, чтобы основные действия, информация и уведомления находились в одном удобном месте и были доступны только авторизованным администраторам.


## Настройка Push

Для настройки Push не нужно устанавливать дополнительные программы.

В настройках панели руководства откройте браузерный генератор VAPID-ключей, создайте пару ключей, затем вставьте **Public Key** и **Private Key** в соответствующие поля на сайте. Пара VAPID-ключей создаётся один раз для проекта. Приватный ключ необходимо хранить в секрете.
