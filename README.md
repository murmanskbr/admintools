# Black Russia — Мурманск Admin Panel v3

Это полностью автономный frontend-прототип без Supabase.

## Демо-доступ

Руководство:
- логин: `admin`
- пароль: `admin123`

Обычный администратор:
- логин: `test`
- пароль: `test123`

## Запуск

Распакуйте архив и откройте `index.html` двойным кликом в браузере.

## Разница ролей

Обычный администратор:
- Главная
- Моя статистика
- Нормативы
- Мои обращения
- Регламент
- Настройки

Руководство:
- всё выше;
- статистика администрации;
- состав администрации;
- общая статистика;
- журнал действий.

## Следующий этап

После проверки интерфейса подключим авторизацию к Supabase Edge Function. Роль должна проверяться на сервере, а не только в JavaScript браузера.
