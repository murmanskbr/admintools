# Black Russia — Мурманск AdminTools

Публичный frontend-репозиторий оболочки панели администрации.

## Возможности интерфейса

- обычный администратор и руководство;
- главная страница и профиль;
- уведомления;
- нормативы;
- обращения;
- состав администрации;
- журнал действий;
- управление доступом;
- регламент;
- водяной знак с никнеймом;
- таймер сессии;
- адаптация для телефона и ПК.

## Архитектура

Репозиторий содержит только публичную оболочку интерфейса.

Серверная авторизация, база данных и интеграции с внешними сервисами размещаются отдельно от публичного frontend-репозитория.

## Структура

- `index.html` — точка входа;
- `css/app-v11.css` — стили интерфейса;
- `js/app-v11.js` — интерфейс, навигация и представления;
- `js/diagnostics.js` — диагностика frontend.

## Примечание

В публичной версии серверная авторизация не выполняется. Форма входа оставлена как часть интерфейса и будет связана с закрытой серверной частью отдельно.
