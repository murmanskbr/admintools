# Black Russia — Мурманск AdminTools

Автономный frontend-прототип панели администрации сервера.

## Текущая версия

- авторизация двух типов пользователей;
- обычный администратор и руководство;
- руководство не видит форму отправки нормативов;
- обычный администратор может выбрать файл, дату, должность и комментарий;
- нормативы сохраняются локально в браузере;
- публичный список никнеймов и должностей администрации;
- никнейм и должность текущего пользователя;
- водяной знак с никнеймом на каждой странице;
- сессия на 3 минуты;
- таймер сессии обновляется при активности пользователя;
- автоматический выход после истечения сессии;
- адаптация для Android, iOS и ПК;
- статистика временно отключена;
- настройки и переключение темы временно убраны.

## Демо-доступ

Руководство:

- логин: `admin`
- пароль: `admin123`

Обычный администратор:

- логин: `test`
- пароль: `test123`

## Структура

- `index.html` — точка входа;
- `css/styles.css` — интерфейс и адаптивность;
- `js/app.js` — авторизация, роли, сессия, нормативы и навигация.

## Важно

Авторизация пока работает локально и предназначена для прототипа. Пароли находятся во frontend-коде и не должны использоваться в рабочей системе. Следующим этапом можно подключить Supabase Edge Function, чтобы проверять пользователя, устройство, токен и роль на сервере.
